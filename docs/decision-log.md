# 判断記録

## 2026-10-22
- 取得したPNG→GIFのHTMLを原資料として`docs/png-to-gif/`に残し、独立したアプリを`apps/png-to-gif/`へ実装してホームへ登録する。
- MP4の時間範囲指定と画面の切り抜きからGIFを作成できるようにする。容量を調整するため、出力幅とFPSを指定できるようにする。
- 外部ライブラリやサーバーへファイルを送らず、PC Chromeの動画デコードとCanvas、同梱GIFエンコーダで変換する。原ファイルは変更せず、作成結果は利用者がダウンロードする。
- 作成前の容量は画像内容を含むサンプルから見積もる。推定であることを表示し、作成後は実測サイズを表示する。
- MP4の編集は、映像を見ながらタイムラインで時間範囲を選び、動画上で切り取り枠を描画・移動・リサイズできる操作を追加する。数値入力と双方向に同期し、同じ設定を容量見込みとGIF出力へ渡す。
- 動画の黒帯や枠線を切り取り座標に含めず、元動画のピクセル座標で範囲を保持する。変換の可否を決める出力上限に達していても、時間範囲・切り取り枠を編集して調整できるようにする。

## 2026-10-21
- `MEP-first-design-assistant`を参考に、共通指示・Claude/Codex設定・役割・検証hook・AI引き継ぎを移植する。
- アプリ本体は機能別の`apps/<機能名>/`、資料は`docs/<機能名>/`に分け、共通HTMLホームから開く。
- 全機能とホームはPC前提。スマホ対応は要件に含めない。
- スクリーンショット注釈ツールも追加。最後のデザイン指示を採用し、元の処理を保ってNeo-Brutalismへ変更する。
- デザインはNeo-Brutalism風。
- 最初のアプリはユーザー提供の`docs/ui-review-tool/ui-review-tool_HANDOFF.md`に記載されたUI指摘ツール。実装後に原資料を同フォルダへ移動する。
- 原資料は仕様の根拠として保存する。記載されている「実装済み・49項目合格」は今回の実装の検証結果として流用しない。
- 参照元に独自スキルはないため、チーム運用・検証・AI引き継ぎの3スキルを新設する。
- スクショ注釈ツールの入力中の文字は、クリック位置を起点として確定後と同じ位置・サイズで描画する。入力欄自体の背景・枠線・影は表示しない。
- ホーム最下部のNEXT UPセクションを削除する。
- 矢印の先端から線がはみ出す描画を修正し、先端形状を選択できるようにする。
- 線幅・文字サイズなどの数値設定を、候補からの選択と直接入力の両方に対応させる。
- UI指摘ツールは、並び順セレクタの再利用で別要素へ指摘を移さない。記録時の対象情報を保持し、識別属性・文脈・候補の一意性で照合する。不確かな場合は元の情報を残して要確認とする。
