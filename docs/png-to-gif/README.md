# PNG・MP4からGIF作成

本体は[アプリ](../../apps/png-to-gif/index.html)。ホームの「PNG・MP4からGIF作成」から起動する。PC Chromeを対象とし、ビルドやサーバーは不要。`file://`で動く。

## できること

- 複数のPNGを追加し、順番・切り替え間隔・繰り返しを設定してGIFを作る。
- MP4を読み込み、開始・終了時間と画面の切り抜き範囲を指定してGIFを作る。
- 出力幅と動画のフレームレートを調整し、作成前に容量の見込みを確認する。
- 作成したGIFをプレビューしてダウンロードする。

## 操作

PNGは「PNG画像を並べる」タブから追加する。ドラッグまたは各画像の「前へ」「後へ」で順番を変え、切り替え間隔を指定する。サイズが異なる画像は先頭画像の比率に合わせ、余白を背景色で埋める。

MP4は「MP4動画を切り取る」タブから読み込む。動画下のタイムラインをクリック・ドラッグして場面を確認し、IN（開始）とOUT（終了）のつまみをドラッグしてGIFにする区間を選ぶ。「動画を再生」で全体、「選択範囲を再生」で指定区間を確認できる。開始・終了の秒数入力と、動画の現在位置を開始・終了に設定するボタンも使用できる。

画面の切り取りは「範囲を描く」を選び、映像上をドラッグして指定する。描画後は枠内をドラッグして移動し、辺・角のハンドルでサイズを調整する。別の範囲を描き直すときは「範囲を描く」に戻す。元動画のピクセル座標を使うX・Y・幅・高さの数値入力とも連動し、「全画面に戻す」で解除する。動画の黒帯や枠線は切り取り範囲に含めない。

タイムラインの各つまみは矢印キーで0.01秒、Shift併用で1秒ずつ調整できる。Home/Endは端へ移動する。切り取り枠・ハンドルは矢印キーで1px、Shift併用で10px調整できる。ドラッグ中のEscは操作前の範囲へ戻す。

タイムラインには6場面のサムネイルと選択区間を表示する。画面外までドラッグしても元動画の範囲内へ収め、切り取り枠は最小1pxを守る。出力のフレーム数・画素数上限を超えていても、映像と編集操作は利用できるので、時間範囲や出力幅を縮めて調整する。読込・変換中は視覚編集も無効になる。

出力幅を決めると、高さは縦横比から自動で決まる。容量を減らす場合は、幅を小さくするか、MP4のFPS・時間を減らす。「GIFを作成」の後で結果と実際の容量を確認し、「GIFを保存」でダウンロードする。

## 容量見込みと制限

設定を変えると、先頭・中央・末尾から最大3フレームを実際に圧縮して容量を再計算する。3フレーム以下なら全フレームを計算した容量を表示する。4フレーム以上はサンプルの平均・最小・最大を全体へ換算する見込みで、動画の他の場面が複雑な場合など、表示範囲を外れる場合もある。作成後の実測サイズを最終的な容量として確認する。容量の単位はB、KiB、MiB（1KiB=1024B）。

処理量を抑えるため、出力は縦横各1280px・240フレーム・合計6000万画素まで。PNGは1枚25MiB・合計150MiB・1枚3200万画素・合計6400万画素まで、MP4は200MiB・元動画3200万画素まで。上限を超える設定は変換前にエラーで知らせる。幅を小さくする、画像を減らす、時間やFPSを減らすことで調整できる。

PNGの初期出力幅は元画像の幅を使い、縦横1280pxに収まるよう調整する。MP4の初期範囲は先頭から最大5秒、FPSは1〜30で指定できる。GIFは時間を10ms単位で記録するため、各フレームの表示時間は丸められる。MP4では累積時間を丸めてから各フレームの差分を取ることで、24/30FPSでも丸め誤差の蓄積を抑える。最後のフレームは指定終了時刻までの残り時間（最小10ms）にする。

## データの扱い

読み込んだファイルと作成結果はブラウザのメモリだけに保持する。外部送信・サーバー保存・ブラウザへの永続保存はしない。再読み込みやタブを閉じると失われるので、必要なGIFはダウンロードする。元のPNG・MP4は変更しない。読み込み失敗や処理の取り消しでは、既に読み込んだデータと最後に成功した作成結果を保持する。

GIFには音声がなく、色数も制限される。PNGの透明部分は選択した背景色へ合成する。MP4はPC Chromeが再生できるコーデックが対象で、拡張子が同じでも非対応の動画は読み込めない場合がある。

## 原資料と実装

[取得した原HTML](PNGからGIF変換_修正版.html)を仕様の出発点として保存している。原資料のPNG追加・並べ替え・プレビュー・速度・繰り返し・GIF保存に、MP4の時間と画面の切り取り、出力幅、容量見込み、取り消しを追加した。製品の実装は`apps/png-to-gif/`が正本。

GIFの構造と圧縮は[GIF89a仕様](https://www.w3.org/Graphics/GIF/spec-gif89a.txt)、動画のシーク完了は[seekedイベントの説明](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/seeked_event)を参照する。

## 検証の再実行

`node scripts/check-workspace.cjs`と`node --test tests/*.test.cjs`で全体とGIFエンコーダ・出力計画を確認する。ffmpegがあれば、独立デコーダーによる全ピクセル比較も実行する。ffmpegがない場合はその試験だけスキップとして出力する。

ブラウザ試験は`PLAYWRIGHT_MODULE=/path/to/playwright node tests/browser/png-to-gif.cjs`で実行する。PC Chromeとffmpegが必要。必要に応じて`CHROME_EXECUTABLE`・`FFMPEG_EXECUTABLE`を設定する。合成PNG・MP4をローカル生成し、証拠をGit対象外の`test-results/png-to-gif/`へ出力する。利用者の実ファイルは使わない。

視覚編集の追加試験は`PLAYWRIGHT_MODULE=/path/to/playwright node tests/browser/png-to-gif-editor.cjs`。横長・縦長・40msの合成動画でタイムライン、切り取り枠、実GIFとの一致を確認する。証拠は`test-results/png-to-gif-editor/`へ出力する。
