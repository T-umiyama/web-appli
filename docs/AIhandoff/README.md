# AI引き継ぎログの運用

形式は参照元を踏襲し、作業日ごとに`YYYY-MM-DD.md`へ記録する。
共通規約は[AGENTS.md](../../AGENTS.md)と[CLAUDE.md](../../CLAUDE.md)の「AI引き継ぎログ」節。

## 読むとき
最新の日付ファイルを読み、未完事項に必要な過去分だけ読む。ファイル・試験の現状を実物で確かめる。

## 書くとき
同じテーマ・フォルダ・成果物の作業はまとめ、作業単位の完了時に1件残す。返信ごとには増やさない。
境界が不明なら書かずに確認する。主担当が子担当の内容も統合する。
日付見出しの直下へ新しいエントリを追加する。過去ログは削除・移動しない。

```markdown
# YYYY-MM-DD

### HH:MM | <実際のモデル名>（<実行環境>）
- **依頼内容**：
- **実施内容**：
- **検証**：実行した確認と実際の結果。未実行・失敗も記載。
- **未完事項**：なければ「なし」。
- **重要メモ**：
- **関連ファイル**：
```

時刻は日本時間。モデル名が不明なら不明と記録する。認証情報や利用者の実データは書かない。
試験結果は[検証記録](../verification.md)、決定は[判断記録](../decision-log.md)、懸念は[未確認事項](../open-issues.md)にも残す。
同じ作業を追加した場合は既存エントリへ追記する。commit・pushはユーザーの依頼時に行う。
