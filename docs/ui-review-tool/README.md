# UI指摘ツール

[アプリを開く](../../apps/ui-review-tool/index.html) / [ユーザー提供の元資料](ui-review-tool_HANDOFF.md)

PC Chrome向けの単一HTMLアプリ。自作のHTMLを読み込み、画面の要素ごとに指摘を付け、AI向けMarkdownをコピーする。元資料を仕様として新しく実装した。元資料の「49項目合格」は今回の検証結果ではない。

## 操作
1. 「フォルダを開く」または「HTMLを開く」で対象を選ぶ。ドラッグでも取り込める。CSSや画像が分かれているアプリはフォルダごと開く。
2. 複数のHTMLがある場合は表示するHTMLを選ぶ。
3. 通常は操作モード。`Q`で選択に切り替え、要素をクリックする。選択中はアプリ側へクリックを渡さない。
4. 指摘を入力してEnterで確定。Shift+Enterで改行。選択は継続し、Escで終了する。
5. 「修正指示をコピー」でAI向けMarkdownを得る。クリップボードを使えなければコピー用ダイアログを表示する。
6. AIが元ファイルを修正したら「再読込」。Handleで開いた場合は元ファイルを読み直す。ファイル入力の代替経路は、同じ対象を選び直して反映する。

赤枠と番号はツール側に描く。リストから要素へ移動できる。削除しても番号を振り直さず、6秒間は復元できる。
空の指摘は破棄し、それが最後の番号であれば番号を再利用する。
別の対象・別のHTMLへ切り替える際は削除前に確認する。リセットは指摘と番号だけを消し、ページを保つ。

## 保存
正本はIndexedDB `ui-review-tool` → `kv` → `state`。
Markdownは派生物で、再インポートしない。ファイル本体は保存しない。
利用可能な場合はFileSystemHandleを保存する。再開時に参照許可が必要なことがある。
Handleを保存できない場合は指摘のみ保存し、同じ対象を開き直す案内を出す。
IndexedDBが使えない場合は保存失敗を表示する。画面を閉じる前にMarkdownをコピーする。

## 読み込みと制約
- ローカルの相対CSS、CSSの再帰的なurl/import、画像、srcset、SVG参照、fetchを解決する。
- 動的画像・動画・音声・linkの相対参照も補助する。
- ESモジュールの相対import、XHR、動的な相対script、複雑なSPA遷移、currentScript.src基準の読込は未対応。
- 別HTMLへの遷移とフォーム送信は停止する。HTMLは選び直す。
- data URLを含むsrcsetはそのまま扱い、警告する。
- 行番号は開始タグとの照合による推定。実行後DOMのセレクタ・祖先・HTML抜粋を併記する。
- プレビューは取り込んだJSを実行する。信頼できる手元のアプリだけを対象とする。同一オリジンであり、隔離環境ではない。
- 検証結果と実機での未確認事項は[全体の検証記録](../verification.md)を参照する。
