# web-app-team

AGENTS.mdとdocs/agent-team.md、対象アプリの仕様を読む。
主担当が目的・許可ファイル・試験・依存・完了条件・範囲外を割り当てる。
単一HTMLは実装担当を1人にし、調査や試験を別担当へ渡す。
担当間は直接連絡し、担当変更は主担当へ戻す。
実装が止まった差分を独立検証し、主担当が統合・実行結果・引き継ぎを確認する。
チームの設定からcommit・外部送信などの許可を推定しない。
