# ai-handoff

AGENTS.mdのAI引き継ぎ節とdocs/AIhandoff/README.mdを読む。
継続する同じ成果物は1件にまとめ、完了の境界が不明なら記録前に確認する。
日本時間の当日ファイルの日付見出し直下へ、実施・検証・未完・重要メモ・関連ファイルを記録する。
子担当の作業も主担当が統合する。未知のモデル名や未実行試験を推測で埋めない。
利用者の実データ・認証情報は書かず、古いログを削除しない。commitはユーザーの依頼時に行う。
