SCREENSHOT ANNOTATOR

スクショ注釈ツール

貼り付ける。書き込む。共有する。
スクショに、伝わるひと手間を。
1. ツール
四角枠はドラッグで範囲指定します。
2. 見た目
注釈をクリックすると選択できます。選択後はドラッグで移動、図形のハンドルで編集、Deleteで削除できます。
選択中のツールに必要な設定だけ表示します。
3. 操作
Ctrl + V：貼り付け
Ctrl + C：編集済み画像をコピー
Ctrl + Z：戻す
Ctrl + Y：やり直し
文字は Enter 確定、Shift + Enter 改行
4. 入出力
画像はこの画面内で処理します。自動保存はありません。再読込・終了前にコピーかPNG保存をしてください。コピーが許可されない場合はPNGをダウンロードします。
100%
スクショをコピーして、この画面で Ctrl+V / Command+V を押してください。
Enterで確定 / Shift+Enterで改行 / Escでキャンセル

画像ファイルを開くこともできます。
